## What this is

"Tail Compass" — an India-first pet-travel planning web app (hackathon-stage MVP).
Tagline: "Plan the journey. We'll look after the tail."

Owner: Rakesh Nerella. **He is a non-coder.** Give complete, step-by-step
instructions he can follow himself. Never assume terminal fluency.
Currency INR, timezone IST, Indian English.

## Stack

- React 18 + Vite 5, plain JavaScript (no TypeScript)
- Node 22, ESM only (`"type": "module"`)
- No framework, no router, no state library, no CSS framework
- Custom Node server (`server.mjs`) wraps Vite in middleware mode and adds one API route
- No database. All data is hard-coded demo data.

## Commands

    npm install
    npm test        # node-based assertion tests, no test framework
    npm run dev     # starts server.mjs on http://localhost:5173
    npm run build   # vite build -> dist/

## How the app flows

5 steps, tracked by `step` state in `App`:
0 Trip check -> 1 Travel options -> 2 Trip status -> 3 Itinerary -> 4 Prepare

The "Compass Check" panel (inside step 2) is the AI feature: paste hotel policy
text -> extract structured constraints -> compare against the pet -> show
COMPATIBLE / CONFLICT.

## Core design rule — do not break this

**The AI extracts facts. It never decides.**
`server/policyExtractor.mjs` returns structured constraints only.
`src/readiness.js` makes every compatibility decision, deterministically.
Scores are derived from rules, never generated by a model.

There is always a non-AI fallback: `extractPolicyConstraints()` in `readiness.js`
is a regex parser that runs when AI is unavailable. Keep it working.

Both paths must return the same shape, validated by `validatePolicyConstraints()`.

## Honesty rules baked into the UI

Every data item carries `verificationStatus` (OFFICIAL / DEMO / NOT_VERIFIED),
`source`, and where possible `sourceUrl` + `lastVerified`. Demo data is labelled
as demo. Never fabricate testimonials, reviews, availability or bookings.
Never present demo data as live or verified.

## Known gaps (as of Aug 2026)

1. **`/api/extract-policy` and `/api/tail-memory` only exist in the dev server.**
   A deployed `dist/` has no backend. Needs serverless functions before launch.
2. **Only Air India is source-backed.** Indian Railways, bus operators and every
   stay/activity are DEMO or NOT_VERIFIED with null limits, by design.
3. **Only Goa has a dataset.** Other destinations are discovery-only and say so.
4. **No image provider for Tail Memory.** The abstraction and UI are complete;
   `/api/tail-memory` returns `{available:false}` until a provider is wired in.
5. **Policy uploads read plain text only.** PDFs and screenshots ask the user to
   paste the text; OCR would need a new dependency.
6. **No database.** All data is in `src/data/*`.
7. **No map.** Deliberately deferred until the core flow is stable.
